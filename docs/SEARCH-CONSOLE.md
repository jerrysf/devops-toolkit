# Google Search Console Setup

Once the site is deployed on its custom domain:

1. Go to https://search.google.com/search-console and add the property.
   Prefer a **Domain** property (DNS verification) so all subdomains and
   protocols are covered; a **URL-prefix** property also works.

2. **Verification options:**
   - *DNS (recommended for Domain property):* add the TXT record at your
     DNS provider (Cloudflare/Route53/etc.). No code changes needed.
   - *HTML meta tag (URL-prefix property):* take the `content` value of
     the provided `google-site-verification` meta tag and set
     `NEXT_PUBLIC_GSC_VERIFICATION=<token>` — the layout emits the meta
     tag when this env var is set. (Wire this in `src/app/layout.tsx`
     `metadata.verification.google` when enabling.)

3. **Submit the sitemap:** `https://<domain>/sitemap.xml` under
   Sitemaps → Add. It's generated by `src/app/sitemap.ts` and updates
   automatically with the article registry.

4. `robots.txt` (`src/app/robots.ts`) allows all crawlers and points at
   the sitemap.

## What to monitor

- **Coverage/Pages** — all 3 articles + index pages should index; the
  checkout pages are `noindex` intentionally.
- **Queries** — the guides target phrases like "crashloopbackoff fix",
  "imagepullbackoff kubernetes", "node notready".
- **Core Web Vitals** — the site is fully static; expect green scores.
