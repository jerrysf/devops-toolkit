# Incident Triage Checklist — First 15 Minutes

A triage sheet for Kubernetes incidents. Print it, keep it in your
runbook, adapt it to your stack. Triage orders by blast radius first,
root cause second.

## 0. Declare and record (0–2 min)

- [ ] Assign an incident commander and a comms owner
- [ ] Start a timeline document — every observation timestamped
- [ ] Confirm which cluster/context you're on:

      kubectl config current-context

## 1. Establish blast radius (2–5 min)

- [ ] What user-facing symptom triggered this? (error rate, latency,
      specific endpoint)
- [ ] Which namespace(s)/service(s) are affected?

      kubectl get pods -A | grep -v Running

- [ ] Check cluster-level health:

      kubectl get nodes
      kubectl get events -A --sort-by=.lastTimestamp | tail -20

## 2. Triage affected workloads (5–10 min)

For each abnormal pod, in order:

- [ ] Pod phase/status (`get pods -o wide`)
- [ ] Recent events (`describe pod <name>` — bottom section)
- [ ] Logs, including the previous container (`logs <name> --previous`)
- [ ] Is it one pod, one deployment, one node, or cluster-wide?

Pattern quick-map:

| Symptom                    | Likely area                        |
|----------------------------|------------------------------------|
| CrashLoopBackOff           | App exit, config, probes, OOM      |
| ImagePullBackOff           | Registry auth, bad tag, network    |
| Pending                    | Scheduling: resources, taints, PVC |
| Unknown / NodeLost         | Node/kubelet failure               |
| NXDOMAIN on ClusterIP svc  | Endpoints empty / selector mismatch|

## 3. Mitigate before fixing (10–15 min)

- [ ] Can you restore service without knowing the root cause?
      (rollback, scale, failover, feature flag)
- [ ] If rollback is available and safe: prefer it over debugging live

      kubectl rollout undo deployment/<name> -n <ns>   # MODIFYING

- [ ] Record the mitigation and its effect in the timeline

## 4. Hand off cleanly

- [ ] Timeline has: symptom, blast radius, commands run, outputs,
      mitigation, current state
- [ ] Root-cause hypotheses ranked, with evidence
- [ ] Next-check owner assigned
